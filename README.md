# PinPo 原型评审台

允许产品经理、设计师和研发人员直接在可交互的 HTML 原型上打点、框选和补充说明，并导出可独立打开、可逐条定位标注的评审文件。

## 适用场景

- 产品原型走查和需求评审
- 多步骤、多状态页面标注
- 弹窗、抽屉、遮罩和 Tab 状态说明
- 向研发或外包团队交付带标注的交互原型/原型修改清单与说明稿
- 保存业务流程完成后的结算页、结果页等动态状态

## 使用方式

仓库中的 **Pinpo.html** 即为完整的 PinPo 工具，不需要安装依赖或启动服务。

1. 下载 pinpo.html。
2. 使用 Chrome、Edge、Firefox 或 Safari 等现代浏览器打开。
3. 点击“导入原型”，选择需要标注的 HTML 文件。
4. 在“浏览模式”中正常操作原型，进入需要标注的页面和状态。
5. 切换到“标注模式”，点击页面创建点位标注，或拖拽创建区域标注。
6. 在左侧标注清单中编辑类型、标题和说明。
7. 根据交付目的选择“导出标注”或“导出评审页”。

> 原型与标注均在浏览器本地处理。

## 功能清单

### 1. 原型导入与再次编辑

- 支持导入 .html 和 .htm 单文件原型。
- 原型通过 iframe srcdoc 运行，保留按钮、表单、页面跳转等真实交互。
- 支持重新导入 PinPo 导出的标注 HTML。
- 重新导入后可以继续新增、编辑、定位和删除标注。
- 导出文件内嵌完整项目数据，并带有完整性校验信息。

### 2. 浏览模式与标注模式

| 模式 | 功能 |
| --- | --- |
| 浏览模式 | 正常操作原型，完成点击、输入、滚动、页面切换和业务流程 |
| 标注模式 | 点击创建点位标注|

浏览模式与标注模式相互独立，避免打标时误触原型，也允许在标注/保存标注前进入特定业务状态。

### 3. 点位标注与区域标注

- 点位标注适用于按钮、文字、输入框、图标等单个元素。
- 区域标注适用于卡片、列表、表单、模块和页面区块。
- 标注编号按照创建顺序自动生成。
- 标注尽量绑定到对应 DOM 元素，而不只是保存屏幕坐标。
- 元素位置变化、页面滚动或窗口尺寸变化时，标记会重新计算位置。

### 4. 六种标注类型（再次感谢wsrongjie的绝妙框架，太清晰了！）

- 交互：点击、返回、跳转、手势和操作反馈
- 样式：颜色、字体、间距、圆角和视觉还原
- 数据：字段、统计数据、接口内容和数据格式
- 状态：默认、选中、禁用、加载、空状态和异常状态
- 疑问：需要产品、设计或研发共同确认的问题
- 逻辑：业务规则、判断条件、流程约束和边界情况

每条标注都可以编辑标题和详细说明。

### 5. 左侧标注清单

- 按编号集中展示全部标注。
- 点击清单项可以选中对应标注。
- 支持一键定位标注位置。
- 支持修改标注类型、标题和说明。
- 支持删除单条标注。
- 显示当前标注数量和本地保存状态。

### 6. 多页面与多状态定位

PinPo 会为标注记录与页面定位相关的信息，包括：

- URL Hash 路由
- 页面根节点和局部页面路径
- DOM 元素锚点路径
- 页面和局部内容指纹
- 弹窗、遮罩、抽屉等浮层上下文
- 文档坐标与视口坐标
- 页面及容器滚动位置

定位标注时，工具会尝试恢复标注所属的单个页面，隐藏同级的其他页面，避免把不同页面同时展开成长页面。

### 7. 场景状态保存与恢复

创建标注时，PinPo 会记录当时的页面场景，包括：

- 激活、选中、展开、显示和隐藏状态
- class、内联样式和常用 ARIA 状态
- 输入框、文本框和下拉框的值
- 复选框选中状态
- 页面与内部滚动容器的位置
- 当前页面路由

点击定位时会先恢复这些状态，再查找标注锚点。

### 8. 动态 DOM 快照

对于必须完成业务流程后才会生成内容的页面，PinPo 会保存页面局部 DOM 快照，例如：

- 结算页统计数字
- 动态结果列表
- 生词本列表
- 运行后生成的文案
- 按钮选中与取消选中状态

评审页定位到此类标注时，会恢复保存时的页面内容，无需评审者重新完成完整业务流程。

为了尽量保留原型交互，恢复过程会优先同步现有 DOM，而不是简单替换整个页面。

> 导入旧标注后，重新进入对应页面并再次导出，PinPo 会为当前可见的标注自动补充快照。

### 9. 自动保存与独立备份

- 标注发生变化后自动写入浏览器 localStorage。
- 支持“恢复本地草稿”。
- 按原型内容建立独立标注备份，降低不同原型之间相互覆盖的风险。
- 本地空间不足时会提示及时导出 HTML。
- 自动保存不能替代正式文件备份，重要标注请及时导出。

## 两种导出文件

### 导出标注（原型可交互）

生成文件：

    原文件名-修改标注.html

特点：

- 保留原型原有页面结构和交互。
- 在页面上显示标注编号和区域框。
- 鼠标悬停或聚焦编号时显示标注详情。
- 根据当前页面和遮挡情况自动显示或隐藏标注。
- 内嵌完整项目数据，可以重新导入 PinPo 编辑。

适合沉浸式检查原型和复盘交互逻辑。

### 导出评审页（原型不可交互）

生成文件：

    原文件名-标注清单.html

特点：

- 左侧浮动目录列出全部标注编号、标题和类型。
- 点击目录项直接跳转到对应标注。
- 自动恢复标注所属的路由、页面状态、滚动位置和动态页面内容。
- 每次只展示标注所属的单个页面，不会把多个状态拼成长页面。
- 定位后高亮标记并显示标注提示。

适合评审、逐条核对问题和交付研发。

## 使用建议

- 先在浏览模式中进入目标页面，再切换到标注模式。
- 对结算页、结果页等动态页面，应在数据完整显示后创建标注。
- 如果同一页面存在多个不同状态，应分别进入对应状态后标注。
- 交付前使用“导出评审页”逐条检查定位是否准确。
- 收到旧版标注缺少快照的提示时，重新访问对应页面后再导出。
- **不要把浏览器本地草稿作为唯一备份** 

## 已知边界

- 当前主要面向单文件 HTML 原型。
- 完全运行在 JavaScript 内存中、但没有渲染到 DOM 的业务数据无法直接展示；PinPo 保存的是用户实际看到的页面状态与内容。
- Canvas、WebGL、视频当前帧等非 DOM 画面不一定能通过 DOM 快照完整恢复。
- 原型依赖的在线字体、图片或接口在离线环境下可能无法加载。
- 原型 DOM 结构发生大幅修改后，旧标注锚点可能需要重新确认。

## 技术特点

- 单文件 HTML、CSS 和 JavaScript
- iframe srcdoc 原型预览
- Pointer Events 标注绘制
- DOM 路径锚点与上下文指纹
- viewport/document 双坐标模式
- MutationObserver 动态跟踪
- 页面场景状态序列化
- 局部 DOM 快照与无损同步
- 内嵌项目数据及完整性校验
- localStorage 自动保存与独立备份
